## What I understood

Class 00 introduced HIMMA — *The Summit of Knowledge*. The core idea is
simple but uncomfortable: **content alone is not enough**. The traditional
model (cram → exam → forget) leaves no asset behind. HIMMA replaces it
with an Operating System: **Goal → Practice → Evidence → Feedback →
Portfolio (V2)**.

The four ideas that hit me hardest were:

1. **Evidence ≠ Perfection.** A focused 5-line answer, a small diagram,
   or one test case is enough — as long as it proves clear thinking.
2. **V1 is allowed to fail.** The grade lives in V2, after feedback.
   This removes the fear of submitting an imperfect first draft.
3. **The Triangulation of Proof:** Artifact (the work) + Process
   (reflection, V1→V2) + Behavior (Show & Tell, defense of ideas).
   One alone is not enough.
4. **Professionalism is in the organization.** A folder named
   `Week-01-Setup/` with `goals.txt` and `reflection.md` already
   communicates more than a file called `assignment.docx`.

## What changed in how I think

Before this class, I treated assignments as something to *finish*.
After Class 00 I see every task as a chance to leave behind a **small
proof** I can put on LinkedIn or GitHub. The folder is no longer a
homework dump — it is a *Memory of Achievement*.
